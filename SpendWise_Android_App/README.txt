SpendWise Android-friendly spending tracker

Files:
- index.html: the app
- manifest.webmanifest: installable web-app metadata
- sw.js: offline shell

How to use on Android:
1. Put this folder on a simple web host (GitHub Pages, Netlify, Cloudflare Pages, or another HTTPS host).
2. Open the HTTPS address in Chrome on Android.
3. Use Chrome's "Install app" / "Add to Home screen" option.

Data is stored in the browser's local storage on the device. Export a CSV backup regularly.
